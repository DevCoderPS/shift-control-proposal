Package များ Feature များ ဈေးတွက်ရန် မေးလေ့ရှိသည်များ

ဒိုင်စာရင်းကို တစ်နေရာတည်းမှာ အလိုအလျောက် တွက်ပေးမယ့်စနစ်

ဒိုင်နဲ့ ကော်မရှင်စားတွေ စာအုပ်ပေါ်ရေး၊ calculator နှိပ်၊ ဖုန်းနဲ့ လိုက်မေးနေရတာတွေကို စနစ်တစ်ခုထဲမှာ ပြောင်းလိုက်ပါ။ ဘာမှ မနားလည်သေးလည်း ရပါတယ်။ Package ၄ မျိုးထဲက သင့်အခြေအနေနဲ့ ကိုက်တာကို ရွေးပြီး၊ လိုတဲ့ feature ကိုပဲ ထပ်ထည့်နိုင်ပါတယ်။ ဈေးကိုလည်း အောက်မှာ ကိုယ်တိုင် တွက်ကြည့်နိုင်ပါတယ်။

ကိုယ့်အခြေအနေက ဘယ်လိုလဲ

နှိပ်ရင် အသေးစိတ်ကို ကြည့်နိုင်ပါတယ်

    စနစ်က ဘာလုပ်ပေးသလဲ

    ဒိုင်က အားလုံးကို ကြည့်နိုင်

    ဒိုင်က ကော်မရှင်စားတစ်ယောက်ချင်းစီကို အကောင့်ပေးပြီး၊ ဘယ်သူ ဘာထည့်ထားလဲ ဘယ်လောက်ရှိလဲ တစ်နေရာတည်းက ကြည့်နိုင်ပါတယ်။

    ကော်မရှင်စားက ဖုန်းကနေ ထည့်

    ကော်မရှင်စားတစ်ယောက်ချင်းစီ ကိုယ့်စာရင်းကို ဖုန်းထဲက ထည့်ရုံပါပဲ။ တခြားသူ့စာရင်းကို မမြင်ရအောင်လည်း ခွဲထားပါတယ်။

    ရှင်းတမ်းကို စနစ်က တွက်ပေး

    ပွဲစဉ် (shift) တစ်ခုချင်းစီရဲ့ စာရင်းကို ခွဲမှတ်ပြီး ရှင်းတမ်းကို အလိုအလျောက် တွက်ပေးတဲ့အတွက် လက်နဲ့ပေါင်းရတာ လျော့သွားပါတယ်။

    Package ၄ မျိုး

    လူဦးရေအလိုက် ရွေးပါ။ ဈေးနှုန်းအားလုံးက တစ်လ အတွက် ကျပ်ငွေဖြစ်ပါတယ်။ ညာဘက်ကို သွားလေ ပါတဲ့ feature နဲ့ ကော်မရှင်စား များလေ ဖြစ်ပါတယ်။

    Feature တစ်ခုချင်း ဘာလဲ

    နည်းပညာစကားတွေ မသုံးဘဲ ရိုးရိုး ရှင်းထားပါတယ်။ Package မှာ မပါတဲ့ feature ကို လိုမှ ထပ်ထည့်လို့ရပြီး၊ ထပ်ထည့်ရင် အောက်ပါ ဈေးတွေ ပေါင်းပါမယ်။

    Package ယှဉ်ကြည့်ရန်

    ကိုယ့်ဈေးကို ကိုယ်တိုင်တွက်ကြည့်ပါ

    လူဘယ်နှယောက်သုံးမလဲ၊ ဘာတွေ လိုချင်လဲ ရွေးလိုက်ရင် Package တစ်ခုချင်းစီမှာ ဘယ်လောက်ကျမလဲ၊ ဘယ်ဟာက အသက်သာဆုံးလဲ ချက်ချင်းပြပါမယ်။

    ၁။ ဘယ်လို သုံးမလဲ

    ယောက်

    ၂။ လိုချင်တဲ့ feature

    ရှင်းတမ်း၊ ငွေပေးချေမှု၊ ဖိုင်ထုတ်ခြင်း၊ လုံခြုံရေး ၂ ဆင့်စစ်ခြင်းတို့က Package တိုင်းမှာ ပါပြီးသားပါ။

      မေးလေ့ရှိတာတွေ

      ဒိုင်နဲ့ ကော်မရှင်စား ဘာကွာလဲ

      ဒိုင်က စာရင်းကို ပိုင်ဆိုင်ပြီး ကော်မရှင်စားတွေကို စီမံသူပါ။ ကော်မရှင်စားက ဒိုင်ဆီက စာရင်းလက်ခံပြီး ကိုယ့်ပိုင်းကို ထည့်သူပါ။ ကိုယ်တစ်ယောက်တည်း ကော်မရှင်စားလုပ်မယ်ဆိုရင် Starter က လုံလောက်ပါတယ်။

      Package မှာ မပါတဲ့ feature ကို နောက်မှ ထပ်ထည့်လို့ရလား

      ရပါတယ်။ ဒီစာမျက်နှာက feature စာရင်းမှာ ပြထားတဲ့ ထပ်ဆောင်းဈေးကို လစဉ်ကြေးထဲ ပေါင်းပါမယ်။ Package တစ်ခုအထက်ကို တက်လိုက်တာက ပိုသက်သာနိုင်ပါတယ်။ အပေါ်က ဈေးတွက်စက်ကို သုံးကြည့်ပါ။

      ကော်မရှင်စား Package ပါတာထက် ပိုလိုလာရင်

      တစ်ယောက်ထပ်တိုးတိုင်း 50,000 ကျပ် ထပ်ပေါင်းပါမယ်။ ကော်မရှင်စားအရေအတွက်ကို တစ်ခါတည်း ဆုံးဖြတ်စရာ မလိုပါဘူး။

      Package ကို နောက်မှ ပြောင်းလို့ရလား

      ရပါတယ်။ လုပ်ငန်းကြီးလာရင် ပိုကြီးတဲ့ Package ကို ပြောင်းနိုင်ပါတယ်။ ပြောင်းတဲ့အခါ ပါဝင်တဲ့ feature နဲ့ လူဦးရေကို အသစ်အတိုင်း ပြန်တွက်ပေးပါမယ်။

      စမ်းသုံးကြည့်လို့ရလား

      ဆက်သွယ်ရန်ကနေ မေးမြန်းနိုင်ပါတယ်။ စမ်းသုံးမှု အခြေအနေကို တိုက်ရိုက် ပြောပြပါမယ်။

      စတင်ဖို့ ဆက်သွယ်ပါ

      ဈေးတွက်စက်မှာ ရွေးထားတာကို ကူးယူပြီး ပို့ပေးလိုက်ရင် လိုအပ်တာကို ချက်ချင်း ပြန်လည်ဖြေကြားပါမယ်။

      ဈေးနှုန်းများကို ဒီစာမျက်နှာထဲက အချက်အလက်အတိုင်း တွက်ထားခြင်းဖြစ်ပါတယ်။
